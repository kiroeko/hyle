# util installed-package probes

These focused projects verify that an installed shared or static HYLE package
can resolve `COMPONENTS util`, propagate its public dependencies, compile the
C++ Registry/demangle surface and the old C-shaped schema/link fixture, and
stage runtime libraries without relying on the HYLE source tree. The latter is
not a native-C product or managed FFI certificate; util review may change it or
declare FFI=N/A.
