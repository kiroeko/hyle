## 本轮发现并关闭的测试缺口

| 能力 | 原先未直接证明的风险 | 新反证 |
|---|---|---|
| DynamicBitSet | copy/move assignment、自赋值、fallible growth 保留旧状态、tiny/large kernel | 赋值/swap、恒失败 allocator、65/4099-bit algebra |
| ByteRingBuffer | copy/move assignment 与 reserve OOM | 内容独立性、move 后状态、失败后 capacity/size 不变 |
| ShardedQueue | 构造到一半 OOM 的回滚 | 第 N 次 allocator failure，析构后 live allocation 精确归零 |
| Concurrent flat/node map | assign OOM、miss、size overflow、visitor throw 后锁释放 | 失败重试、`SIZE_MAX` reserve、throw 后立即重新查询 |
| StringInterner | 旧测试没有保证 slot 真被复用；构造/acquire OOM 未直接观察 | 同一字符串确定落同 shard 并复用唯一 free slot，stale generation 仍失效；失败可重试且 teardown 无泄漏 |
| UTF conversion | UTF-16/32 来源的 malformed 与六方向 required capacity 不完整 | 四条来源错误路线都不部分写；六方向精确 size query |
| Obs metrics | 有符号/无符号反向溢出、NaN quantile、零 multiplicity 特值 | fail-fast、typed InvalidArgument 与不提交 sample |

审计中删除了一个拟新增的“非空 null span”用例：C++ `std::span` 本身要求合法连续范围，
`span(nullptr, 1)` 不是合法 public consumer input，不能用测试 UB 冒充库的 invalid-input 责任。测试也没有
读取 `StringId` 私有 bit layout 或假设随机 hash 分布。
