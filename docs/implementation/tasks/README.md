# 历史任务与调查

以下目录保留技术事实，不是当前待办。记录中的治理流程、状态迁移、审批、预算、截止时间和
恢复条件均已废止；其中命令也不会自动执行。当前安排见[当前工作主线](../../developer/current-work.md)。

- [Compute](compute/)：算子、数值、Provider、资源与性能调查。
- [Graph](graph/)：编译、状态、并发和执行管线。
- [构建](build/)：工具链、依赖、安装与交付问题。
- [跨组件调查](project/)：需求、能力覆盖和消费者组合。
- 其他目录按组件名称保存相应记录。

实验结果仅适用于记录中的源码、环境和比较边界；失败和未验证项保留原貌。
纯治理记录已清理，需要追溯时读取 Git 历史。
