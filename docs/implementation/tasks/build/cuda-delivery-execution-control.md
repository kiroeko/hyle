## 强制边界

执行器只约束经过它的命令。当前命令工具没有仓库可设置的前置拦截；本任务不能声称阻止代理
另写脚本或直接调用 shell。旧入口退出本批执行路径，AGENTS 的本批说明指向唯一入口；真正的
工具层防绕过不在本轮实现范围内。不能把单入口约定写成系统级强制保证。
