每格仅普通Compute/Graph发现，installed头/库/运行库必须来自实际rename后的prefix；把
consumer源码复制到隔离目录，编译不借canonical src/include或trusted private头。profile
有CPU时运行public CPU Direct/Graph；真实native profile另外运行公开native Direct/Graph。
Linux cpu-cuda必须真实FI native paged/ragged与D256，不以CPU消费代签CUDA；Windows
native paged未准入，验证具名拒绝。WSL native Vulkan只有包资格，不记GPU数学PASS。
