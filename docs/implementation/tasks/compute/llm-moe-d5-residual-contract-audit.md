## 三批施工顺序

1. **残余语义/承载**：从固定GLM/DeepSeek实际源码区分权重存储、激活量化、累加与状态合同；
   对照已接入库及已登记ds4/llama.cpp的真实消费方式，一次列清20格的共同缺口与具名候选。
2. **Vulkan两个问题**：数值方面对照上游长位置RoPE和实际反馈状态；性能方面先离线比较
   原A/A表格值、配对统计和计时/同步源码。候选有明确变化前不启动GPU或完整P1。
3. **受影响批验与终审**：有可靠候选才另定有限产品FIX；同批集中接线，稳定后一个不可变候选
   统一编译、串行正确性/必要交付/适用P1；复用未变化证据，最后D6汇总。

## 审计结果

A1–A4均已完成，见[批量审计证据](../../../../evidence/research/llm-moe-d5-residual-contract-audit/README.md)。

[独立工具修正卡](llm-moe-d5-vulkan-measurement-balance.md)。本审计停止，不扩查全生态。
