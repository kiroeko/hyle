- **已完成：** 已盘点的单机功能及本轮明确的模型／请求组合整改；工程入口与许可整改。
- **现在做：** MTP自动流水的重录与额外提交开销；共同执行和状态缓存边界继续收敛。
- **接下来：** 先降低MTP后继的录制与准备成本，再推进其它GPU热点；不把同步对照的收益当成默认路径收益。

已实现单项保留原结果；联合复审继续纳入新发现，不以旧100%排除。
