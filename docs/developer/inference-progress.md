## 现在在哪里

HYLE的目标是完整推理引擎，基础模块仍可独立使用。目前主要建设底层，用真实Qwen模型检验它们。

- **已完成：** 前批已列单机功能与模型／请求组合整改；工程入口与许可整改。
- **本次完成：** Qwen同步、packed prefill和递归验证目标步骤已消费共同驱动；7项有限检查通过，真实Qwen K1全部非计时字段保持。共同执行架构仍未完成。
- **当前位置：** Qwen连续普通／K1、同步／packed／递归目标步骤与GLM普通续算使用同一驱动；模型仍保留数学、状态及Head发布。模型执行对请求账簿的依赖仍需清理，第二完整模型、多卡／多机仍未验证或实现。
- **现在做：** 分清模型结果、原提交见证和请求账簿的职责及借用寿命，再复审结构不同的实际组件。草稿词表等独立性能改动继续隔离。
- **仍未交付：** 多模态图片、通用模型加载／tokenizer及服务器API。本阶段不以这些应用能力为前置。

当前顺序：**共同执行驱动与静态适配 → 结构不同的原组件消费同一驱动、相关有限检查 → 集中性能优化与完整对照**。架构阶段只做正确性和明显退化检查，不启动独立GPU／词表性能候选。

已实现单项保留原结果；联合复审继续纳入新发现，不以旧100%排除。
当前实现路线是单机CPU、单GPU及CPU＋单GPU；多卡／多机列入架构边界审查，尚未实现。
