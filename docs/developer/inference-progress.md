## 现在在哪里

HYLE的目标是完整推理引擎，基础模块仍可独立使用。目前主要建设底层，用真实Qwen模型检验它们。

- **已完成：** 前批已列单机功能与模型／请求组合整改；工程入口与许可整改。
- **本次完成：** Qwen／Kimi共用完整阶段成功交接，三阶段Source链已复现旧顺序拒绝并修正；7项组件测试及12条有限消费者通过。
- **新发现：** GLM请求演示核了credit，但未传到模型前缀选择，只覆盖自然单发分支；需随完整步骤适配补齐。
- **现在做：** 共同完整执行架构：收敛冷程序／执行槽、完整步骤与模型适配、普通／MTP状态发布及多模型／存储域边界。
- **接下来：** 先完成共同架构及相关有限检查，再集中处理普通／MTP性能。条件后继未验证原型已保存并撤出产品，不计为实现完成。

当前顺序：**共同架构 → 相关有限检查 → 集中性能优化与完整对照**。架构改动保留必要的正确性与明显退化检查，不并行推进独立性能候选。

当前实现路线是单机CPU、单GPU及CPU＋单GPU；多卡／多机列入架构边界审查，尚未实现。
