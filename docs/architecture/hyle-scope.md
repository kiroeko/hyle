# HYLE 产品范围

HYLE 是 C++23 基础加速库，提供可组合的内存、数据结构、SIMD、调度、I/O、异构计算与 Graph。
推理引擎是当前主要消费者；渲染与资源流送、数值管线和异步服务也用于检验通用机制。

当前推理目标是多系统上的单机 CPU、CPU＋一张 GPU、单 GPU，不是跨机器协同推理。

## 提供什么

- 合理的算法和数据结构复杂度。
- 减少分配、复制、同步、系统调用和调度成本。
- 贴合 cache、NUMA、SIMD、CPU/GPU 的数据与执行形状。
- 可组合的所有权、寿命、错误、取消、完成与观测机制。

基础库需要完整的正常用户旅程，不能只有构造或 benchmark 接口。
实现可以由 HYLE、成熟依赖或现有原语组合承担；成熟路线更好时优先采用它。
公开 API 应自然、默认安全，成本可见，可选能力不给默认热路径增加无关开销。
组件职责和依赖保持清晰、无环，见[组件与依赖](capability-factorization.md)。

## 与上层的边界

模型文件解析、tokenizer、采样、KV/prefix 缓存策略、层与专家放置政策、请求调度和 serving 属引擎。
HYLE 提供它们需要的资源、状态版本、搬运、依赖、计算和完成机制；CPU/GPU 组合见
[组合设计](compute-next-stage.md)。模型、量化格式和布局需求见[共同目录](model-compute-catalogue.md)。

场景、材质、渲染算法、窗口/present、业务协议、数据库和云部署同样属于相应产品。
通用的寿命、失败、并发和关闭问题不能仅以“上层处理”掩盖，应提供可靠组合路线。

当前不实现完整模型框架、自动微分、分布式训练、通用分布式 runtime 或 HIP/ROCm。
新需求根据真实消费者和维护成本讨论，不受旧状态机或固定审批流程控制。

## 交付与支持

提供完整源码、headers＋static、headers＋shared 三种 C++ 交付。
不承诺跨编译器/STL 的 C++ ABI，当前没有独立 C API 或外语绑定。
系统、设备、ISA、dtype、布局和格式支持分别说明；编译成功不等于真机计算与性能已经验证。
未支持、未验证和已知失败如实区分。
