## 在架构中的位置

它在依赖图哪个节点、上游谁依赖它、属于哪条接缝（如 completion 脊 / C-ABI 边界 / allocator 注入）。指向 `roadmap.md` 第一节的位置。

## 具体事务（做什么）

- [ ] 文件/接口清单（要建哪些 `.h`/`.cc`）
- [ ] 关键数据结构 / 函数签名
- [ ] 借入的第三方（封 adapter 的边界）
- [ ] 明确**不做**的（留给后续里程碑的）

## 交付物

- 头文件 + 实现 + 测试 + 基准（若适用）
- 能编译、能跑的最小演示

## 验收标准

- **编译**：三编译器 / 相关平台过
- **测试**：覆盖达 Tier 标准（T0≈100%、T1≥90%、T2/3 80%+）
- **正确性闸门**（按需）：TSan/ASan/UBSan 过；无锁结构压力/模型检查；故障注入测错误路径
- **基准**（若性能相关）：对标项 + 不退化阈值
- **具体可验证条件**：本里程碑"算完成"的硬指标
