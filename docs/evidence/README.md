# 原始实验数据

这里保存实验源码、CSV、JSON、日志、尺寸、哈希和复现资产。目录中的 README 解释对应数据的
输入、环境和边界，只代表那次实验，不是当前产品支持表。

本目录已从仓库根目录 `evidence/` 移到 `docs/evidence/`。历史日志、JSON 和归档中的路径及哈希
保留原样；查找其中以 `evidence/` 开头的仓库相对路径时，在当前工作树使用 `docs/evidence/`。
独立复现脚本已调整仓库定位；归档内的冻结源码仍对应当时的版本。

解释结果时说明源码版本、硬件、工具链、参数及测量边界；性能比较使用相同输入和完成语义，
冷准备、热执行与资源占用分别报告。失败与未运行项如实保留。

已删除过程文档的历史引用固定到清理前的 Git 版本，避免链接到含义已经改变的现行说明。
离线可用 `git show <commit>:<path>` 读取；[实施材料](../implementation/README.md)说明追溯方式。
当前接口和限制见[用户文档](../user/README.md)。
