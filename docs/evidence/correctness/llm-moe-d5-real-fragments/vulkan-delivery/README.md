## DeepSeek GGUF：逐画像裁决

旧聚合测试失败不能代表循环中的每份画像都失败。现有
[三路线证据](../deepseek-gguf-three-route/README.md)中，Vulkan attention/压缩的GGUF失败
trace仅属于 `UD-Q8_K_XL`。本次因旧日志未固定当前驱动身份，直接复用已编译的公开消费者，
对两入口各运行一次原 attention/压缩测试，不改原数值门、不新增原生数学探针。

- **UD-Q4_K_XL：两入口通过。** 两个固定测试均明确遍历Q4与Q8；本次所有Q4子案例无失败或
  跳过。其余必需region复用原完整Vulkan批次中的逐项通过结果，R01精确绑定词表参数索引5；
  图sink分类修正后的通过结果单独复用。逐region映射及源码身份核对见汇总。
- **UD-Q8_K_XL：两入口 RUN_FAIL。** 每入口attention仍有24个数值断言失败，压缩有456个；
  官方压缩另外有888个失败。失败批次没有改写为PASS；官方完整画像以R11冷拒绝记账，
  这里的压缩失败另外保留。Q8画像至少R09不能通过原误差门。
- 相比`91af7569`，相关Vulkan产品、成熟库、DeepSeek配方和profile事实未变；共用语义helper
  仅新增默认空的准备字段和未使用的诊断函数，不改变旧计算与误差门。仍未用替代成熟实现
  解决已定位的长位置精度问题，不扩大为所有上游都不可能的结论。
